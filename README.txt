===================================================
  한국어 수업 관리 시스템
  울산 외국인 근로자 지원센터
===================================================

[ 설치 방법 ]

1. Node.js 설치 (https://nodejs.org) - LTS 버전 권장
2. 이 폴더에서 명령 프롬프트(CMD) 열기
3. 아래 명령어 실행:
      npm install
4. 서버 시작:
      node server.js
   또는 start.bat 파일 더블클릭

5. 브라우저에서 접속:
      http://localhost:3000

---------------------------------------------------

[ 기본 계정 ]

관리자 아이디:  admin
관리자 비번:    admin123

(처음 로그인 후 비밀번호를 변경하세요)

---------------------------------------------------

[ 사용 방법 ]

[관리자]
1. admin 계정으로 로그인
2. 선생님 추가 → 아이디/비밀번호 설정
3. 학생 추가 → 반 배정
4. 모든 그룹, 학생 현황 확인 가능

[선생님]
1. 부여받은 아이디/비밀번호로 로그인
2. 그룹/반 만들기
3. 수업 추가 (날짜, 제목)
4. 각 수업에서 출석 체크 및 성적 입력 (0~100%)

---------------------------------------------------

[ 인터넷 배포 시 ]

- PORT 환경변수로 포트 변경 가능: PORT=8080 node server.js
- 데이터는 /data 폴더에 자동 저장됩니다
- 백업: /data 폴더 전체 복사
